# Admir Isufi – Garten & Entrümpellung

Statische One-Page-Website (HTML, CSS, JavaScript – ohne Build-Schritt).

- `index.html` – Seite mit allen Bereichen
- `assets/css/styles.css` – Design (Farben und Abstände als CSS-Variablen in `:root`)
- `assets/js/main.js` – Menü, WhatsApp-Links, Kontaktformular
- `assets/img/` – Logo, Fotos und Bildausschnitte
- `assets/fonts/` – selbst gehostete Schriften (Bricolage Grotesque, Hanken Grotesk), keine Verbindung zu Google

Lokal ansehen: `python3 -m http.server` im Ordner starten und `http://localhost:8000` öffnen.

Das Kontaktformular braucht keinen Server: Die Anfrage wird fertig ausgefüllt in WhatsApp oder im E-Mail-Programm geöffnet.
